# Little By Little

> A 2D platformer built for **Gamedev.js Jam 2026**
> Theme: **Machines**

A lone wheel wakes up in a post-apocalyptic wasteland with no memory
of its past. Piece by piece, it rebuilds itself — uncovering the 
secrets of a world left behind by humanity.

---

## 🛠 Tech Stack

| | |
|---|---|
| Language | JavaScript |
| Framework | Phaser 3 |
| Build Tool | Vite |
| Package Manager | npm |

## 📋 Prerequisites

- Node.js v16 or higher
- npm

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/ReiiiBriii/LITTLE-BY-LITTLE.git

# Navigate to project
cd LITTLE-BY-LITTLE

# Install dependencies
npm install

# Run development server
npm run dev
```

Then open your browser at `http://localhost:5173`
