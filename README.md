Tech Stack
Language: JavaScript
Framework: Phaser
Build Tool: Vite
Package Manager: npm
Development Tool: Visual Studio Code

Prerequisites
Node.js (v16 or higher)

Installation
Once the repository is cloned
open terminal and navigate to the project directory
cd LITTLE-BY-LITTLE
npm install

Running the Application
open terminal and navigate to the project directory
cd LITTLE-BY-LITTLE
npm run dev
then open the local server
